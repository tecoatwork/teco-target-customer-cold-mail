# teco-target-customer-cold-mail

将公司与产品优势、客户背景调查、触达切入点和FABMP结合，生成5封针对性B2B开发信。

Copyright (c) 2026 tecoatwork

## 输出

默认5个不同角度的首封开发信备选，每封含标题、正文和独立的中文审核说明。也支持“1封首信+4封跟进”。不自动发送。

## 工作流程

1. 整理我方公司实力、产品差异化及可用证据。
2. 使用客户分析Skill核实目标公司和联系人，选择真实业务切入点。
3. 比较八类切入点：（1）消费终端差评反查；（2）产品线空缺与细分场景机会；（3）企业动态与招聘/扩张信号；（4）同业标杆脱敏案例；（5）地缘与环保合规预警；（6）总成本 TCO 优化；（7）第二供应源/供应链冗余安全保障；（8）行业避坑自查表。
4. 完成Feature → Advantage → Benefit（客户公司）→ Meaning（联系人）→ Proof。
5. 写5封邮件，检查事实、差异、角色相关性与CTA。

## 安装与依赖

把本目录放入助手的技能目录，文件夹名为 `teco-target-customer-cold-mail`。Codex常用目录为 `~/.codex/skills/`。

同时安装 [teco-target-customer-analyse](https://github.com/tecoatwork/teco-target-customer-analyse)。需要可用的联网搜索/阅读能力才能重新核查目标现状；没有联网时可分析用户提供的有来源资料，并明确限制。不需要邮件账号或CRM访问。

## 使用示例

```text
使用 $teco-target-customer-cold-mail。
我方公司：[公司与可对外披露实力]
主推产品：[型号、差异化卖点、测试或案例]
目标客户：[公司官网]
联系人：[姓名/职责；未知则写目标角色]
邮件语言：英文
请输出5个不同角度的首封开发信，附中文FABMP说明。
```

需要跟进序列时写明“1封首信+4封跟进”，并提供真实的已发送内容与回复（如有）。未提供核心目标或产品时会先整理缺口，不虚构事实。

## 范围与隐私

通用包内置方法说明，不依赖私人Obsidian目录；不包含公司机密、客户档案或真实外联案例。公司优势和客户线索需由使用者提供或在具体任务中核查。不得将低置信度性格推断用作操纵依据。

已做格式、路径和规则一致性检查；尚未用真实客户实跑，也没有回复率验证。MIT许可见LICENSE。

### 如何使用

提供客户原话、帖子或当前卡点即可；Skill按问题选择相关方法，不要求每次调用全部理论。例如：

```text
客户测试过样品后没有回复。请区分已知事实和可能原因，给一个低压力的下一步；没有报告或证书的内容不要代我承诺。
```

在各Skill原有职责内使用：图解助手解释分支，开发信助手起草邮件，Post助手组织专业内容，评论助手生成相关回复。调用本参考不会扩大Skill的职责，也不授权发送消息、点赞或发布。

### 新增判断方法

- 处境理解：把“客户怕担责”等猜测改成可纠正的中性问题。
- 信息表达：先明确判断口径，再给证据、限制及可追溯资料；热度与重复不充当证据。
- 供应商切换：考虑准入、试样、库存衔接和责任，条件适合才提出范围明确的验证。
- 角色识别：社交互动、专业影响、采购执行与签字授权分开核实。
- 工作复盘：适用时标准化核验与记录，比较有效需求和真实阶段推进，不承诺成交提升。
